Safety Check

Two small security tools for learning what red flags look like. Everything runs in your browser, and nothing you type is sent anywhere.

    A learning tool, not a security product. A link can pass every check and still be dangerous, and a safe link can trip a check. When unsure, don’t click: type the website’s address yourself.

      Never type a password you really use into a tool you don’t fully trust. Use made-up examples.

      About these tools
      • Privacy: the checks run as JavaScript inside your browser. Nothing is uploaded, saved, or tracked by this page.
      • The link checker looks only at the text of the link. It doesn’t visit the site, so it can’t tell whether the site is actually malicious.
      • The password checker uses simple rules and a short list of common passwords. The crack-time guess is rough and assumes an attacker trying 10 billion guesses a second.
      • Better habits than any tool: use a different password for every account, let a password manager create and store them, and turn on two-factor login wherever it’s offered.
