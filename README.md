# Safety Check

Free learning tools that show what red flags look like in links and passwords.

**Live site:** https://zakria2323.github.io/safety-check/

## What it does

- **Link checker:** paste a link or domain and it points out common phishing red flags, like no https, look-alike characters, fake brand names, and pressure words such as "verify" or "login". Each check comes with a short explanation of why it matters.
- **Password checker:** scores a password as you type, shows which checks pass or fail, and gives a rough guess at how long it would take to crack.

## Privacy

Everything runs in your browser. Nothing you type is uploaded, saved, or tracked.

## Limits

This is a learning tool, not a security product.

- A link can pass every check and still be dangerous, and a safe link can trip a check.
- The link checker only reads the text of the link. It does not visit the site.
- The crack-time estimate is rough and assumes an attacker making 10 billion guesses per second.

## Built with

HTML, CSS, and plain JavaScript in a single file (`index.html`), with no libraries. Hosted on GitHub Pages. Built while learning cybersecurity and web development.

## Run it yourself

Download `index.html` and open it in any browser.
